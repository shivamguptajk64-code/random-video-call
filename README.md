# 📹 Random Video Call Application

A real-time random video calling web application that connects users with random peers for video chats, built using **HTML, CSS, and JavaScript**.

---

## 🚀 Features

- 🎥 **Real-time Video & Audio Chat**: Smooth video streaming between connected users.
- 🔀 **Random Peer Matching**: Connects you with available random users instantly.
- 🔕 **Media Controls**: Mute/unmute microphone and enable/disable camera.
- 📱 **Responsive Design**: Works across desktop and mobile browsers.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
